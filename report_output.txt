}

--- Ошибка: пустое имя ---
Команда: python dep_visualizer.py -p   -u https://registry.npmjs.org
Ошибка: Пустое имя пакета

--- Ошибка: неверный URL ---
Команда: python dep_visualizer.py -p express -u ftp://registry.npmjs.org
Ошибка: Некорректный URL репозитория

--- Ошибка: нет файла ---
Команда: python dep_visualizer.py -p A -u missing.json -t
Ошибка: Файл не найден: missing.json

--- Ошибка: имя пакета в тесте ---
Команда: python dep_visualizer.py -p pkg1 -u test_diamond.json -t
Ошибка: Для тестов имя пакета должно быть из заглавных латинских букв

--- Ошибка: глубина < 0 ---
Команда: python dep_visualizer.py -p A -u test_diamond.json -t -d -1
Ошибка: Глубина не может быть меньше 0

--- Ошибка: формат файла ---
Команда: python dep_visualizer.py -p A -u test_diamond.json -t -o out.jpg
Ошибка: Файл должен быть в формате .png
