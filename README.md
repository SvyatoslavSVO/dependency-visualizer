# Dependency Graph Visualizer (npm)

Инструмент командной строки для анализа и визуализации графа зависимостей npm-пакетов без использования сторонних библиотек (на чистом Python).

## Описание проекта

Программа осуществляет извлечение данных о зависимостях пакета, строит направленный граф зависимостей с помощью итеративного алгоритма поиска в глубину (DFS), разрешает циклические ссылки, вычисляет топологический порядок загрузки модулей и формирует визуализацию в формате Graphviz (.dot/.png), а также в виде текстового ASCII-дерева.

### Основные особенности
- **Zero Dependencies**: реализован строго на стандартной библиотеке Python (`urllib`, `argparse`, `json`, `subprocess`).
- **Алгоритм DFS без рекурсии**: обход графа выполняется на явном стеке, что предотвращает переполнение стека вызовов (`RecursionError`) на глубоких деревьях зависимостей.
- **Защита от циклов**: отслеживание посещённых вершин исключает бесконечные циклы при взаимных зависимостях пакетов.
- **Топологический порядок загрузки**: post-order обход графа для корректной последовательности инициализации зависимостей.
- **Два режима работы**:
  - `Режим онлайн`: получение актуальных метаданных пакета напрямую из официального реестра через npm Registry HTTP API.
  - `Тестовый режим`: построение графов на основе локальных конфигурационных файлов с синтетическими репозиториями (JSON или текстовый формат).

---

## Требования
- Python 3.8 или новее.
- Установленный пакет [Graphviz](https://graphviz.org/) (утилита `dot` в системном `PATH`) для локального рендеринга `.png`. Если утилита отсутствует, программа автоматически генерирует изображение через fallback-запрос.

---

## Параметры командной строки

| Флаг | Полное имя | Описание | Обязательный | По умолчанию |
| :--- | :--- | :--- | :---: | :---: |
| `-p` | `--package` | Имя корневого пакета для анализа | Да | — |
| `-u` | `--url` | URL реестра npm или путь к локальному файлу (в тестовом режиме) | Да | — |
| `-t` | `--test-mode` | Включение тестового режима работы с локальным файлом | Нет | `False` |
| `-d` | `--max-depth` | Максимальная глубина обхода графа | Нет | `3` |
| `-o` | `--output` | Имя выходного PNG-файла графа | Нет | `graph.png` |
| `-a` | `--ascii-tree` | Вывод дерева зависимостей в виде ASCII-графики в терминал | Нет | `False` |
| `-l` | `--load-order` | Вывод расчетного порядка загрузки пакетов | Нет | `False` |

## Примеры использования

### 1. Реальный npm-пакет из реестра
Получение графа для пакета `express` с выводом ASCII-дерева и порядка загрузки:
```bash
python dep_visualizer.py -p express -u [https://registry.npmjs.org](https://registry.npmjs.org) -d 2 -a -l -o express_graph.png
